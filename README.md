# kasper_mafia 🎭

Telegram-бот, который ведёт игру «Мафия» в группах: набор игроков, ночные ходы в личке,
дневные обсуждения, голосование, последнее слово, статистика и топ игроков.

## Роли

| Роль | Команда | Что делает | С какого числа игроков |
|---|---|---|---|
| 🎩 Дон | Мафия | Голосует за жертву (решает при ничьей) + ищет комиссара | всегда |
| 🤵 Мафия | Мафия | Выбирает жертву вместе с семьёй | 7+ |
| 💼 Адвокат | Мафия | Прикрывает игрока от проверки комиссара | 11+ |
| 🕵️ Комиссар | Город | Проверяет игрока или стреляет | 4+ |
| 🩺 Доктор | Город | Лечит (не одного и того же подряд, себя — раз за игру) | 5+ |
| 💃 Любовница | Город | Отвлекает игрока — тот теряет ночной ход | 7+ |
| 🧥 Бомж | Город | Видит, кто приходил к игроку ночью | 8+ |
| 🪓 Маньяк | Сам за себя | Убивает каждую ночь, побеждает один на один | 9+ |
| 👮 Сержант | Город | Получает проверки комиссара, заменяет его после смерти | 10+ |
| 🤡 Самоубийца | Сам за себя | Побеждает, если его повесят днём | 12+ |
| 👨‍🌾 Мирный житель | Город | Обсуждает и голосует | остальные |

Мафии примерно 1 на 3,5 игрока.

## Как проходит игра

1. `/game` в группе → игроки жмут «Присоединиться» (открывается бот, вход в один клик).
2. Роли приходят в личку. Мафия видит свою семью.
3. **Ночь:** ходы кнопками в личке. Мафия может переписываться через бота. В группе ночью молчат.
4. **Утро:** бот объявляет погибших (и их роли). Погибшие могут прислать последнее слово.
5. **День:** обсуждение → голосование в личке (ход голосов виден в чате) → «Вешаем?» 👍/👎 в группе.
6. Кто пропустил 2 голосования подряд — выбывает. Если 3 круга подряд никто не умер — ничья.

## Команды

В группе: `/game`, `/begin`, `/extend`, `/stop`, `/leave`, `/top`.
Везде: `/rules`, `/roles`, `/stats`, `/help`.

## Настройка

1. Создайте **нового** бота у @BotFather и возьмите токен.
2. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN`.
3. Добавьте бота в группу и сделайте **администратором** с правом «Удаление сообщений» —
   тогда мёртвые и ночные сообщения будут удаляться.

## Запуск

```bash
pip install -r requirements.txt
python -m bot.main
```

Docker / Render: `docker build -t kasper_mafia . && docker run --env-file .env kasper_mafia`.
На Render создайте Web Service из этого репозитория (Docker), добавьте переменную `BOT_TOKEN`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest tests/test_rules.py        # правила
python -m tests.simulate          # полные игры ботов-игроков через поддельный Telegram API
python -m tests.scenarios         # крайние случаи лобби
```

## Структура

```
bot/
  main.py              запуск, health-сервер, команды бота
  config.py            настройки и тайминги
  db.py                статистика (SQLite)
  texts.py             тексты и атмосфера
  keyboards.py         кнопки
  game/
    roles.py           роли и описания
    models.py          игрок, игра, фазы
    rules.py           чистая логика: раздача ролей, ночь, голосование, победа
    manager.py         ход игры: лобби → ночь → день → итоги
  handlers/            команды группы, личка, кнопки, статистика, удаление сообщений
tests/                 юнит-тесты и симуляция игр
```
